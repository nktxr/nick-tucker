# Project Context: cf-react

## Overview

This project is a React-based application, designed for deployment on Cloudflare workers.
This application/site should be a personal website:

## Home page

- Should have a top centred profile picture, found in the sources folder
- It should have a title displaying 'Nick Tucker'
- Underneath this, 3 buttons - one linking to a blog page, an about page, and one linking to a resume page
- It should have a bottom of social links for Github profile url, linkedin, email address, medium

## Blog page

- There should be a blog page, with a structure set out for how to add new entries, with 3 created as examples
- These will have a picture, a title, and standard text

## About page

- This will be a static page where I will fill in about me, some informal chat around experience, and information about hobbies etc

## Resume page

- This should render the contents of my pdf resume. Generate an example that can be used

## Tech Stack

- **Framework:** React/Vite
- **Platform:** Cloudflare (Workers)
